# Graphical specification organization

swa.ml 2.1.

The catalog pairs each graphical concept with context, canonical drawing, syntax, constraints and source identities. The style is original monochrome swa.ml notation, not a claim of SysML notation conformance. Every grammar production/keyword has graphical coverage or an explicit text-only rationale in spec/notation.json.

Draw direction per port member; distinguish queue-bearing connection from boundary forwarding. Show schedules separately from operation signatures, nested operations without capture, literal multiplicity indexes, ordered source-state transitions and platform Node placement. Timing must distinguish declared contracts from identified observed evidence. Keep layout/geometry outside semantic source and preserve the same identities in General Box in box and Tree.

[Graphical notation](GRAPHICAL_NOTATION.md), [the generated catalog](GRAPHICAL_CATALOG.md) and [worked diagrams](GRAPHICAL_EXAMPLES.md) are the maintained presentation contract.
